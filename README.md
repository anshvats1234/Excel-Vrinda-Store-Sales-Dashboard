**Excel Vrinda Store Sales Dashboard**

**Project Overview**
This project presents an interactive Excel dashboard for analyzing Vrinda Store sales performance. The dashboard provides insights into sales trends, customer demographics, order status, top-performing states, and sales channels.

**Tools Used**

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning

**Dashboard Features**

- Orders vs Sales Analysis
- Men vs Women Sales Comparison
- Age Group Analysis
- Order Status Analysis
- Top 5 States by Sales
- Sales Channel Analysis
- Interactive Filters using Slicers

**Key Insights**

- Women contribute more sales than men.
- Amazon is the leading sales channel.
- Maharashtra generates the highest sales.
- Most orders are successfully delivered.
